// turbo-all
1. **Analyze Data Structure**: Use `pandas` to read the first few rows of the dataset. Identify messy column names.
2. **Standardize Columns**: Use the `DataCleaner.clean_column_names` tool to normalize column names to `snake_case`.
3. **Verify and Export**: Run a final check on the cleaned data and save it to the output/processed directory.
4. **Report Results**: Provide a summary of the cleaned column names.
